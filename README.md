# Kaur Muskanpreet UI Garden Build Checks

This is a React + TypeScript project that includes:

- ESLint + Prettier for code quality
- Husky pre-commit hooks
- React Testing Library tests
- Storybook stories for components

## Available Scripts

- **Lint:** `npm run lint`
  Lints all `.ts` and `.tsx` files using ESLint.

- **Format:** `npm run format`
  Formats all code using Prettier.

- **Test:** `npm test`
  Runs all unit tests using React Testing Library.

- **Commit:** Git pre-commit hook will automatically lint, format, and run tests.

## Running the App

```bash
# Install dependencies
npm install

# Run development server
npm start
